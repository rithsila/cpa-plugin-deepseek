# Release matrix: one line per published artefact.
#
# Columns: <goos>/<goarch>  <github runner>
#
# The runner must have a C toolchain that can target its line's platform. All
# macOS targets build on macos-latest: Apple's clang ships a universal SDK, so
# the arm64 runner produces the amd64 artefact too. macos-13 (the old Intel
# runner) is retired and its jobs queue forever, so it is not used.
#
# Cross-compiling c-shared from Linux to macOS or Windows needs a cross toolchain
# we do not ship. Windows is deliberately absent: c-shared on windows/amd64 needs
# mingw, and this matrix only lists platforms that build green.
#
# build.sh, scripts/package-release.sh and .github/workflows/release.yml all
# read this file through scripts/platforms.sh, including how a line is parsed,
# so they cannot disagree about the matrix.
linux/amd64 ubuntu-latest
darwin/arm64 macos-latest
darwin/amd64 macos-latest
