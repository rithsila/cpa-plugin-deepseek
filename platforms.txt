# Release matrix: one line per published artefact.
#
# Columns: <goos>/<goarch>  <github runner>  <toolchain>
#
# The target list mirrors the platforms CLIProxyAPI itself publishes, because a
# plugin is useless on a host nobody ships. The toolchain column tells the
# release workflow how to get a C compiler for that target; this plugin is a
# c-shared library, so every platform needs one.
#
#   native            the runner's own toolchain already targets it
#   zig               cross-compile with zig cc (no native runner exists)
#   msys2-mingw64     MSYS2 mingw64 gcc on a Windows runner
#   msys2-clangarm64  MSYS2 clangarm64 on a Windows runner
#
# build.sh, scripts/package-release.sh and .github/workflows/release.yml all
# read this file through scripts/platforms.sh, including how a line is parsed,
# so they cannot disagree about the matrix.
